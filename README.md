# BLOCK RIVALS 3D 🔫🧱

ロブロックスのライバル風3D FPSです。ブロックアリーナでWAVEごとに押し寄せる敵を倒す一人称シューターです。

## 遊び方

- 開始時はロビー画面から始まります
- ロビーで最初の武器を選べます（ライフル／ピストル／ショットガン）
- 「バトルスタート」ボタンで直接出撃、または「ロビーを歩く」で歩ける3Dロビーに入り、光るゲートをくぐってバトル開始
- ヘッドショットボーナス、リロード、ダッシュ＆ジャンプあり
- HP・スコア・ミニマップ付きHUD
- ゲームオーバー画面から「ロビーに戻る」こともできます

PCはWASD＋マウス（ポインターロック）、スマホは仮想スティック＋スワイプ視点＋FIREボタンで遊べます。

## 使い方

`index.html` をブラウザで開くだけで遊べます。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で main ブランチを選択してください。
